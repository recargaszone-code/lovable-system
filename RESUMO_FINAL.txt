   Verificar: GitHub mostra seus commits


PASSO 3: Criar Web Service (5 minutos)
──────────────────────────────────────
   1. Abrir: https://dashboard.render.com
   2. Clicar: "New +" → "Web Service"
   3. Conectar: seu repositório GitHub
   4. Preencher:
      - Name: lovable-dashboard
      - Region: Oregon
      - Plan: Starter ($7/mês)
   5. Clicar: "Environment" e adicionar variáveis:
      - CASTLE_PK (seu pk_...)
      - FIREBASE_API_KEY (seu AIzaSy...)
      - PROXY_URL (seu proxy)
      - GMAIL_USER (seu email)
      - GMAIL_APP_PASSWORD (sua senha)


PASSO 4: Deploy! (2 minutos)
──────────────────────────
   - Clicar: "Create Web Service"
   - Render faz tudo automaticamente
   - Build + Deploy + Go Live
   - URL: https://lovable-dashboard.onrender.com
