## 🎯 3 Passos Rápidos (10 min)

### 1️⃣ Script (1 min)
```bash
node adjust-for-render.js
```

### 2️⃣ Git Push (2 min)
```bash
git add .
git commit -m "chore: prepare for Railway"
git push origin main
```

### 3️⃣ Railway Deploy (7 min)
1. Abrir: https://railway.app
2. Clicar: "New Project" → "Deploy from GitHub"
3. Conectar GitHub & escolher repo
4. Preencher variáveis:
   - CASTLE_PK
   - FIREBASE_API_KEY
   - PROXY_URL
   - GMAIL_USER
   - GMAIL_APP_PASSWORD
5. Clicar: "Deploy"
6. Aguardar ~2 min
7. **PRONTO!** ✨
